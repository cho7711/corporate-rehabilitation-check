# 법인회생 가능성 기초진단 위젯

골든타임센터 아임웹 홈페이지에 연결하기 위한 서버 없는 기초진단 프로토타입입니다.

## 파일

- `index.html`: GitHub Pages에서 바로 표시할 미리보기 페이지
- `widget.js`: 질문, 점수 계산, 화면 디자인, 결과 문구가 들어 있는 위젯 본체

## 계산 구조

하나의 “회생 가능성 점수”로 단정하지 않고 다음 세 지표를 별도로 계산합니다.

1. 위기 긴급도: 지급곤란, 연체, 집행 위험, 현금 보유기간, 현금흐름, 임금·세금 체납
2. 사업 계속 가능성: 영업 유지, 매출 기반, 영업이익 가능성, 위기 원인, 사업계획, 계속기업가치, 신규자금, 변제재원
3. 자료 신뢰도: 재무·세무자료, 채권자·자산 목록, 특수관계인 거래와 편파변제, 회계·형사 분쟁

위기 긴급도와 사업 계속 가능성을 조합해 결과 유형을 정하고, 자료 신뢰도가 낮을 때는 별도 경고를 표시합니다.

## 아임웹 연결 코드

GitHub Pages 주소가 `https://GITHUB-ID.github.io/REPOSITORY/`라면 아임웹의 기존 **코드 위젯**에 다음 코드를 넣습니다.

```html
<div id="rg-rehab-diagnostic"></div>
<script src="https://GITHUB-ID.github.io/REPOSITORY/widget.js"></script>
```

`GITHUB-ID`와 `REPOSITORY`를 실제 값으로 바꿔야 합니다. 계산은 방문자의 브라우저에서 실행되며 입력값은 저장하거나 전송하지 않습니다.

## 게시 전 필수 검토

- 담당 변호사가 질문, 가중치, 결과 문구를 검토할 것
- 개인정보를 추가로 입력받지 않을 것
- 상담 신청은 기존 아임웹 상담 페이지로 이동시킬 것
- 모바일과 PC 실제 게시 화면에서 점검할 것
- “회생 가능/불가능” 확정 표현이나 성공률·채무탕감률 보장 표현을 사용하지 않을 것

## 면책 문구

본 결과는 입력된 제한적 정보를 기초로 한 일반 안내입니다. 법원의 회생절차 개시·인가 여부, 채무조정 가능 범위 또는 사건 결과를 보장하지 않으며, 구체적인 법률·회계 검토를 대체하지 않습니다.
